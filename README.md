# CargoCalc — C# / ASP.NET Core

Учебный веб-проект для расчёта и сравнения грузоперевозок.

## Что умеет
- Хранить заказчиков и перевозчиков.
- Создавать заявки на перевозку.
- Добавлять предложения перевозчиков с ценой и сроком.
- Показывать самый дешёвый и самый быстрый варианты.
- Рассчитывать вариант с лучшим балансом цены и времени.
- Хранить данные в SQLite в файле `cargocalc.db`.

## Как открыть в Microsoft Visual Studio
1. Распакуйте архив в отдельную папку.
2. Откройте Visual Studio.
3. Нажмите **Открыть проект или решение** (Open a project or solution).
4. Выберите файл `CargoCalc.csproj`.
5. Дождитесь восстановления NuGet-пакетов. Если появится запрос доверия/восстановления — подтвердите.
6. Вверху выберите запуск `https` или `http` и нажмите зелёную кнопку ▶ (или F5).
7. Браузер откроет сайт. Если автоматически не открылся, адрес обычно будет показан в окне запуска.

## Требования
- .NET 8 SDK
- Visual Studio 2022 с рабочей нагрузкой **ASP.NET and web development**.

## Примечание
При первом запуске база `cargocalc.db` создаётся автоматически и наполняется тестовыми данными. Это локальная учебная версия, не предназначенная для публикации в открытый интернет без дополнительной защиты.
